# Meko's BiliVRCParser

把 B 站视频 / 直播一键解析成 **VRChat 能直接播放的直链**，并自动复制到剪贴板。

> by Meko · Edge / Chromium 浏览器扩展 · v1.1.0

## ✨ 特性

- **视频解析**：在 B 站视频页工具栏「···」右边生成「解析」按钮，点击得到**音画合一的 mp4 直链**（最高 720P）
- **直播解析**：在任意直播间信息栏（主播名/关注 那一组）右边生成「解析」按钮，点击得到 **HLS(m3u8) 直播流**
- **纯本地运行**：直接请求 B 站官方接口，**不经过任何第三方服务器**
- **纯匿名**：`credentials: 'omit'`，不读取、不依赖你的登录状态
- **零侵入**：按钮用独立悬浮层 + 坐标贴合，不修改 B 站 DOM，不会让顶栏消失
- **多P 支持**：自动识别当前分集（`?p=N`）

## 📦 安装

1. 打开 Edge，地址栏输入 `edge://extensions`
2. 打开左下角「开发人员模式」
3. 点「加载解压缩的扩展」，选择本项目文件夹
4. 刷新任意 B 站页面，工具栏「···」右边即可看到「解析」按钮

> 详细使用说明见 [`使用说明.txt`](./使用说明.txt)

## 🎯 使用

| 场景 | 按钮位置 | 复制的内容 |
| --- | --- | --- |
| 视频页 | 工具栏「···」右边 | mp4 直链（720P，音画合一） |
| 直播页 | 主播名/关注组右边 | HLS m3u8 直播流 |

## ⚠️ 已知限制

- **视频最高 720P**：B 站单文件 mp4 通道（durl）上限就是 720P；1080P+ 只存在于 DASH（音画分离）通道，需要合并才能播
- **直播地址约 1 小时过期**：过期后重新点「解析」获取新地址
- **不合并 DASH**：1080P 需要 ffmpeg 合并，本插件不做（保持轻量纯本地）

## 📁 文件结构

```
manifest.json    插件清单（MV3）

background.js    后台（仅打开设置页）
options.html/js  设置页（可选自定义解析接口）
使用说明.txt      使用文档
icons/           图标
```
