============================================================
  Meko's BiliVRCParser  使用说明
  B站视频 / 直播  →  VRChat 直链解析
  版本 1.1.3
============================================================

【一、安装（Edge 浏览器）】

1. 打开 Microsoft Edge
2. 地址栏输入  edge://extensions  回车
3. 打开左下角「开发人员模式」开关
4. 点击「加载解压缩的扩展」
5. 选择本文件夹（里面有 manifest.json 的那个）
6. 加载成功后，扩展列表会出现「Meko's BiliVRCParser」


【二、视频解析】

1. 打开任意 B 站视频页（www.bilibili.com/video/BVxxxx）
2. 视频下方工具栏「···」的右边，有蓝色【解析】按钮
3. 点击它
4. 链接会自动复制到剪贴板，页面右下角弹出提示
   （提示里会显示画质和是第几集）
5. 打开 VRChat，把链接粘贴到视频播放器里播放即可


【三、直播解析】

1. 打开任意 B 站直播间（live.bilibili.com/房间号）
2. 直播画面顶端信息栏（主播名 / 人气 / 关注 那一组）的右边，
   会出现【解析】按钮
3. 点击它，会自动复制 HLS(m3u8) 直播流地址
4. 打开 VRChat，粘贴到播放器（需要播放器支持 HLS，
   例如 ProTV / VideoTXL）


【四、注意事项】

· 视频最高只能 720P
  这是 B 站接口的限制：VRChat 能播的「单文件 mp4」通道（durl）
  上限就是 720P；1080P 及以上只存在于 DASH（音视频分离）通道，
  需要合并成单文件才能播，本插件不做合并。

· 直播地址约 1 小时过期
  直播流地址带签名和过期时间，过期后重新点一下【解析】拿新地址即可。

· 纯本地运行
  插件直接请求 B 站官方接口，不经过任何第三方服务器。
  请求默认匿名发出，不读取、也不依赖你的登录状态。
  只有在被 B 站风控拦截（返回 HTTP 412）时，才会自动改用携带设备
  cookie 的方式重试一次；扩展不会读取、也不会外传任何 cookie 内容。

· 按钮会自动贴合位置
  视频页贴在工具栏「···」右边；直播页贴在「主播名/关注」那一组右边。
  页面结构变化时会自动重新计算位置。


【五、常见问题】

Q：视频页看不到【解析】按钮？
A：确认已在 edge://extensions 正确加载扩展，并刷新 B 站页面。
   只有视频播放页（/video/、/list/、/bangumi/play/）会显示按钮。

Q：画质能不能更高一点？
A：视频最高 720P，这是接口限制，不是插件的问题（详见「注意事项」）。

Q：需要登录 B 站吗？
A：不需要。请求默认匿名，不读取你的登录状态。

Q：点击解析提示失败？
A：个别视频可能受限（付费 / 地区限制 / 仅 App 可看），
   或直播间未开播。稍后重试即可。
   如果提示「B站风控拦截了请求」，多半是海外 IP 或开着 VPN / 代理，
   关掉代理、等十几秒再点一次通常就能过。

Q：用国外网络能解析吗？
A：可以。海外 IP 的匿名请求有时会被 B 站拦成 HTTP 412，
   插件会自动换一种请求方式重试，多数情况下能正常解析。

Q：为什么第一次看不到按钮？
A：加载扩展后需要刷新页面（F5），按钮才会注入。
